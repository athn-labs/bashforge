# Filesystem

This module focuses on working efficiently with files and directories in Linux.

The goal is not only to learn Bash commands, but also to understand how administrators diagnose and solve filesystem-related problems.

## Topics Covered

- Recursive file search
- File permissions
- Disk usage
- Symbolic links
- Archives and compression

## Challenges

- [ ] Largest Files
- [ ] Old Files
- [ ] Empty Directories
- [ ] Duplicate Files

## Final Utility

After completing this module, all developed utilities will be integrated into:

```text
tools/filesystem.sh
```

This utility will provide a simple interface for common filesystem administration tasks.

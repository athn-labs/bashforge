# BashForge

BashForge is a hands-on Linux administration project focused on learning Bash through practical real-world scenarios.

Instead of learning commands in isolation, every topic is introduced by solving a realistic system administration problem. Each solution becomes a reusable utility, and every topic concludes with a practical toolkit.

## Objectives

- Improve Bash scripting skills
- Learn Linux administration fundamentals
- Build reusable command-line utilities
- Practive solving real operational problems
- Develop automation-oriented thinking

## Repository Structure

'''text
bashforge/
├── topics/
│   ├── filesystem/
│   ├── processes/
│   ├── networking/
│   ├── logs/
│   └── automation/
└── tools/
'''

- **topics/** contains learning modules grouped by subject.
- **tools/** contains complete utilities built from the knowledge gained in each module.
